### 1 *(Type A)*

The angle is from $+x$, so cosine goes with $x$.

$F_x = 20\cos 40° = 15.3$ N, $\quad F_y = 20\sin 40° = 12.9$ N.

Check: $\sqrt{15.3^2 + 12.9^2} = 20$ N ✓.

### 2 *(Type A)*

Sizes: $15\cos 60° = 7.5$ and $15\sin 60° = 13.0$. The ball goes left, so $x$ is negative; it goes up, so $y$ is positive.

$v_x = -7.5$ m/s, $\quad v_y = +13.0$ m/s.

### 3 *(Type A)*

The angle is measured from the **vertical**, so the roles swap: the vertical component touches the angle (cosine) and the horizontal component is across from it (sine).

$F_x = 80\sin 25° = 33.8$ N (to the right), $\quad F_y = 80\cos 25° = 72.5$ N (up).

Check: the rope is close to vertical, and the vertical component is much larger ✓.

### 4 *(Type B)*

$A = \sqrt{12^2 + (-5)^2} = 13$.

Reference angle: $\tan^{-1}(5/12) = 22.6°$. The vector points right and down, so it is **22.6° below the $+x$ axis** (equivalently −22.6°, or 337.4° counterclockwise from $+x$).

### 5 *(Type B)*

Speed: $\sqrt{(-6.0)^2 + 8.0^2} = 10$ m/s.

A calculator gives $\tan^{-1}(8.0 / -6.0) = -53.1°$. That is the wrong quadrant: the velocity points up and to the left. The reference angle is $53.1°$ above the $-x$ axis, so the angle from $+x$ is $180° - 53.1° = 126.9°$.

### 6 *(Type C)*

| | $x$ (m) | $y$ (m) |
|---|---|---|
| $\vec A$ | 5.0 | 0 |
| $\vec B$ | $7.0\cos 60° = 3.5$ | $7.0\sin 60° = 6.06$ |
| **sum** | 8.5 | 6.06 |

Size: $\sqrt{8.5^2 + 6.06^2} = \sqrt{109} = 10.4$ m. Direction: $\tan^{-1}(6.06/8.5) = 35.5°$ above $+x$.

Check: $10.4$ is between $8.5$ and $5.0 + 7.0 = 12.0$ ✓.

### 7 *(Type C)*

$\vec A - \vec B = (4 - 1,\ 3 - 5) = (3,\ -2)$.

Size: $\sqrt{3^2 + 2^2} = \sqrt{13} = 3.6$. Direction: $\tan^{-1}(2/3) = 33.7°$ **below** $+x$ (the $y$-component is negative).

### 8 *(Type D)*

(a) $A_x = A\cos\theta$ shrinks from $A$ down to 0, while $A_y = A\sin\theta$ grows from 0 up to $A$. The size $A$ itself never changes.

(b) They are equal when $\cos\theta = \sin\theta$, at $\theta = 45°$ (each is then $0.707\,A$).

(c) No. Sine and cosine never exceed 1, so a component is never larger than the vector. Geometrically, the vector is the hypotenuse, the longest side of the right triangle.

### 9 *(Type D)*

(a) **7**: the vectors point the same way (0° between them), so the sizes add.

(b) **1**: they point in opposite directions (180° between them), so the smaller cancels part of the larger.

(c) **90°**: at right angles the sum is $\sqrt{3^2 + 4^2} = 5$. (Any sum between 1 and 7 is possible, depending on the angle.)

## Self-check answers (from the lesson)

1. **Sine.** From the $y$-axis, the $x$-component is the side *across* from the angle.
2. **False.** It holds only when the vectors point the same way; otherwise the sum is smaller.
3. The size is $\sqrt{(-3)^2 + 4^2} = 5$. Left and up means the **second quadrant**.
