# AP Physics 1: a connected course in 30-minute lessons

Short, clearly explained lessons for **AP Physics 1 (algebra-based)**, written so that every idea connects to the one before it. Each lesson has the same shape: a plain-language explanation, the formulas, the common traps, worked examples, and practice problems of several *types*, each with a method for attacking it.

- **Exam:** Wednesday, May 5, 2027, afternoon session. Confirm with your school's AP coordinator.
- **Pace:** 3 to 5 sessions a week, up to 30 minutes each. See [ROADMAP.md](ROADMAP.md).
- **Starting point:** a math refresher (Unit 0), then the College Board's eight units in order.

## How one 30-minute session works

| Min | Step |
|---|---|
| 0–3 | **Warm-up.** Two quick questions from earlier lessons (spaced recall). |
| 3–13 | **Read** the lesson: where it fits, the idea, the formulas, the traps. |
| 13–19 | **Worked examples.** Cover the solution, try it, then compare. |
| 19–28 | **Practice.** The ★ problems in the lesson's `practice/` file. |
| 28–30 | **Self-check.** Note what felt shaky; it becomes tomorrow's warm-up. |

Solutions live in a separate file from the problems so the answer isn't in view while you think.

## Conventions

- **Notation** follows the AP style: $v_x$, $x_0$, $a_x$, and so on.
- **Math** is written in LaTeX (`$...$`), which GitHub renders directly.
- **Images are code.** Every diagram and graph is generated by a short script in `images/src/`, so it is exact and easy to change. To rebuild them all: `python tools/build_images.py` (needs Python with `matplotlib`).
