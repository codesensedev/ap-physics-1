# Problem types and how to approach each

Every lesson's practice problems are tagged with one of these types. Physics questions on the AP exam mix and combine them, so it helps to recognize which one you are looking at.

| Type | You'll recognize it by | The core move |
|---|---|---|
| **Quantitative** | numbers given, a number wanted | the [five-step method](problem-solving-method.md) |
| **Symbolic** | "in terms of $m$, $g$, $\theta$..." | same method, stay in letters; check units and extreme cases |
| **Qualitative reasoning** | "increases, decreases, or stays the same?" | find the equation, see how the quantity depends on what changed, hold the rest fixed |
| **Graph analysis** | a graph is given or you must sketch one | ask: what do the slope, the area and the shape mean? |
| **Representation translation** | "draw a free-body diagram / energy bar chart / graph" | the same physics in another language; make sure all versions agree |
| **Experimental design and analysis** | "design an experiment", "what should be plotted?" | name the variables, linearize, interpret the slope |
| **Paragraph argument** | "justify", "explain", "argue" | claim → principle → how it applies here → conclusion |
| **Multi-statement conceptual** | "which of these are true (select two)?" | judge each statement on its own |

## Approaches

### Quantitative
Five steps: Draw, Define, Choose, Solve, Check. Keep a **table of knowns** with signs. Check the result a second way when you can.

### Symbolic
Do the same steps but never substitute numbers. Finish by checking *units* (does the answer have the right dimensions?) and *limits* (does it behave sensibly when a quantity goes to zero or very large?).

### Qualitative reasoning
1. Write the relevant equation.
2. Say which quantity changes and which stay **fixed**. State this out loud; it is where most mistakes hide.
3. Read off the dependence: proportional, inverse, squared...
4. Answer in a sentence with the reason: "The distance is four times as large because it depends on $v^2$."

### Graph analysis
Ask three questions of every graph: **What does the slope mean? What does the area under the curve mean? What does the shape tell me?** Check the units of slope and area: they tell you what the quantity is.

### Representation translation
Pick one representation you trust (often a sketch or free-body diagram), build the others from it (equation, graph, bar chart), and check that they tell the same story. Disagreement between two representations means one has an error.

### Experimental design and analysis
1. **Variables:** what do you change (independent), measure (dependent), keep fixed (controlled)?
2. **Procedure:** which instruments? how many trials? how do you reduce error?
3. **Linearize:** choose what to plot so the relationship is a straight line (for example, $x$ against $t^2$).
4. **Interpret:** what does the slope (and intercept) represent, in physics terms?

### Paragraph argument
Write in four moves: **Claim** (your answer), **Principle** (the law or relationship you rely on), **Application** (how it applies to *this* situation, using the given facts), **Conclusion** (tie it back to the claim). Use the physics vocabulary of the lesson.

### Multi-statement conceptual
Don't hunt for "the right answer". Mark each statement true or false on its own merits, then pick the ones that survive. Test doubtful statements with an extreme or simple case.
