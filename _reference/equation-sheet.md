# Equation sheet (grows with each lesson)

Each formula comes with what it means and *when to use it*. On the exam you will be given the College Board's own equation sheet, so practise with that one too. This page is the annotated version for learning.

## Unit 0: Math tools

| Formula | Meaning | Use it when |
|---|---|---|
| $a^2 + b^2 = c^2$ | Pythagorean theorem (right triangle, $c$ = hypotenuse) | you know two sides, want the third |
| $\sin\theta = \dfrac{\text{opposite}}{\text{hypotenuse}}$ | sine | you need the side *across* from the angle |
| $\cos\theta = \dfrac{\text{adjacent}}{\text{hypotenuse}}$ | cosine | you need the side *touching* the angle |
| $\tan\theta = \dfrac{\text{opposite}}{\text{adjacent}}$ | tangent | you have the two legs, or need the angle |
| $A_x = A\cos\theta,\quad A_y = A\sin\theta$ | components of a vector ($\theta$ from the $+x$ axis) | you know the size and the angle |
| $A = \sqrt{A_x^2 + A_y^2}$ | size of a vector | you know its components |
| $\theta = \tan^{-1}(A_y / A_x)$ | direction (check the quadrant!) | you know its components |
| $R_x = A_x + B_x,\quad R_y = A_y + B_y$ | sum of two vectors | adding vectors |

## Unit 1: Kinematics

| Formula | Meaning | Use it when |
|---|---|---|
| $a_x = \dfrac{\Delta v_x}{\Delta t}$ | acceleration = rate of change of velocity (slope of $v$–$t$) | definition; reading graphs |
| $v_x = v_{x0} + a_x t$ | velocity after time $t$ (constant $a$) | displacement is not involved |
| $x = x_0 + v_{x0}t + \tfrac{1}{2}a_x t^2$ | position after time $t$ (constant $a$) | final velocity is not involved |
| $v_x^2 = v_{x0}^2 + 2a_x(x - x_0)$ | links velocity and displacement (constant $a$) | time is not involved |
| $\Delta x = \tfrac{1}{2}(v_{x0} + v_x)\,t$ | displacement from the average velocity (constant $a$) | acceleration is not involved |

Symbols: $x$ position, $x_0$ initial position, $\Delta x = x - x_0$ displacement, $v_x$ velocity, $v_{x0}$ initial velocity, $a_x$ acceleration, $t$ time. All are **signed**: the sign says which way along the axis.
